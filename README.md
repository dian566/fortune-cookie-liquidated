A program that writes one fortune cookie line to `/output/entry.txt`:
a fortune for a crypto trader who has just been liquidated. Entered
in make.fun's "Fortune Cookie for the Liquidated Trader" bounty.

## Run it

```sh
python3 main.py
```

The program writes the entry line to `/output/entry.txt` (89
characters, 16 words, one line, no trailing newline). Running it
again writes the exact same bytes.
